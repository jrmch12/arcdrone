- Beta 1→0.3, seed=12

- Batch eval: mean 3.195m, 28% close, 8% landed
- Interesting: Good descent (median z=0.144m), but worse horizontal approach

## Key Insights
1. **Training eval_reward is NOT a good metric** — high variance due to spawn position differences
2. **Augmentation on raw frames (preserving diff channels) helps** — iter2 is best student
3. **Action interpolation helps slightly** but less than augmentation
4. **The vision gap is fundamental**: teacher median 0.43m vs best student 2.16m (5x worse)
5. **Diff channels matter**: corrupting them (aug_iter1b) was catastrophic
6. **Low beta (0.3) is OK** with action interpolation but not with Bernoulli sampling

## Architecture (Current — with fixes)
- CNN(32,64,64)→GAP→64 + proprio(51→norm→64) → fusion MLP(256,128, tanh, activate_final=True)
- vel_estimator(134→128→64→3, relu)
- action_head(131→512→512→256→128→20, tanh)
- Teacher: 72-dim privileged → MLP(512,512,256,128, tanh, activate_final=True) → 128-dim features

## Key Insights (Updated)
1. **Tanh activation match is critical**: student fusion now bounded [-1,1] like teacher → embed loss drops significantly
2. **Lower beta_end is essential**: β=0.5 causes covariate shift, β=0.1 lets student learn independence
3. **Action interpolation DAgger works well**: smooth blending prevents catastrophic divergence
4. **Pixel augmentation (raw frames only) helps**: brightness, contrast, noise applied to raw; diffs recomputed
5. **Training eval_reward is unreliable**: high variance, use batch eval with distance metric instead
6. **Two-phase training is effective**: first learn features at high β, then learn independence at low β
